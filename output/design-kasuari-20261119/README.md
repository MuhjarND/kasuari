## Cakupan Halaman

| Kelompok | Halaman dan penerapannya |
| --- | --- |
| Operasional | Dashboard; register banding dan satker; daftar belum dikirim/dicabut; detail perkara dan para pihak; monitoring sinkronisasi |
| Administrasi | SIPP per empat satker dan direktori modul; blangko/template; data pengguna dan edit/status/password; profil dan identitas satker |
| Layanan | Login; filter laporan dan preview PDF; Hatibinwasda/Hatibinwasbid; layanan CCTV Badilag |
| Komponen turunan | Jenis Blangko, Variabel, tambah/edit, konfirmasi, pencarian, filter, pagination, kosong/error memakai pola tabel dan formulir versi yang dipilih |

Sembilan lembar final berisi 12 tipe layar per versi (36 tampilan konsep).
Komponen turunan tidak diberi halaman terpisah; mengikuti pola komponen konsisten.

## Batasan

- Seluruh versi light mode, termasuk sidebar dan header.
- Ikon berwarna pada menu, angka, kategori, status, filter dan aksi.
- Akses administrator, hak pengguna, sinkronisasi manual, dan fitur aplikasi tetap mengikuti kode aktual.
- Mockup tidak mengaktifkan fitur notifikasi, ekspor tambahan, atau CCTV langsung.
- Kop dan format PDF resmi tetap mengikuti dokumen acuan yang telah diberikan, bukan detail raster konsep.
- Berkas dengan akhiran final/ikon yang ditautkan di atas adalah pilihan terakhir; draft lain tidak dimasukkan ke paket ZIP.
