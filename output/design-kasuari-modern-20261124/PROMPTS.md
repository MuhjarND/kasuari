# Konsep KASUARI Modern

24 November 2026. Mockup dibuat dengan built-in Image Gen. Tidak ada perubahan pada kode aplikasi, database, atau hosting.

- [Operasional](01-operasional.png): dashboard, register, detail perkara, monitoring.
- [Administrasi](02-administrasi.png): SIPP, template dokumen, pengguna, profil. Jenis blangko, variabel, dan identitas satker mengikuti pola tabel/form yang sama.

Logo dan identitas aplikasi dipertahankan. Isi, status, urutan tahap, tanggal, nama, peran, dan aksi di gambar merupakan contoh visual. Implementasi mengikuti menu, hak akses, alur perkara, dan format PDF resmi yang sudah ada. Pratinjau CCTV bukan tayangan langsung.

Design like premium contemporary operations software: clean geometric typography (Inter, 24px headings / 13-14px body), crisp hairline separators, strong alignment and breathing room, efficient content density, no redundant cards. Use many meaningful FLAT DUOTONE glyphs: colored icon tiles for navigation sections and key numbers, unboxed pairs on contextual tabs and field groups, status symbol with text, icon-only actions in table cells. Sidebar white, slim, use logo + listed sections: Dashboard, SIPP, Register Perkara, Monitoring Sinkronisasi, Pengawasan, CCTV Online, Kelola. Keep actual submenu names where relevant. Native date fields, clear visible actions, minimal important text, coherent Indonesian labels, readable contrast. Illustration only, all records fictional; no private names, real addresses or real CCTV footage. Give more visual space to the working content than to the sidebar. Thin 6px rounded corners only where appropriate, no nested or floating section cards.
